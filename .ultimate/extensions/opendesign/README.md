# OpenDesign

Pulls a design out of OpenDesign into `designs/<slug>/` as a read-only snapshot, so the implementation work in Ultimate
starts from the design the user made.

OpenDesign (https://github.com/nexu-io/open-design, Apache 2.0) is local-first: the app runs a daemon, and its MCP
server is only a thin wrapper around that daemon's HTTP API (`apps/daemon/src/mcp.ts`), so this talks to the daemon
directly and needs no MCP. **Pull only** — OpenDesign owns the design, this repository owns the implementation, and
nothing here writes back to OpenDesign. `designs/` is a snapshot: edit the implementation, then pull again.

Both the tools and the actions are also callable outside the UI: codemode
`ultimate.action('opendesign', 'pull', { project: 'Landing' })`.

## Tools for agents

| tool            | what it does                                                                                                                                                         |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `design_active` | The project and file the user has open in OpenDesign right now, or one plain sentence saying nothing is. It expires about five minutes after their last interaction. |
| `design_list`   | Every project on the daemon, each with what the repository already holds of it, for choosing when nothing is open.                                                   |
| `design_pull`   | `{ project? }` — pull a project (or the one open) into `designs/<slug>/`, answering what was written and what changed since the last pull.                           |

## Actions for the UI

`server.ts` exports `actions`; `web.tsx` calls them through refs of the same names.

| action     | args                   | result                                                                                                           |
| ---------- | ---------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `overview` | —                      | `{ status: 'ok', url, designsDir, token, active, projects }` or a `Blocked` screen (below).                      |
| `active`   | —                      | `{ status: 'ok', active }`, or `Blocked`.                                                                        |
| `list`     | —                      | `{ status: 'ok', projects }`, or `Blocked`.                                                                      |
| `pull`     | `{ project?: string }` | `{ project, slug, dir, entry, frame, frameError?, files, change, skipped, at }`; throws its sentence on failure. |

`Blocked` is `{ status: 'unreachable' | 'unauthorized' | 'failed', url, message }`: the panel shows the message and the
url instead of empty rows. A pull throws instead, because a click asked for it — the message is the one to act on.

## What a pull writes

```
designs/<slug>/
  index.html, app.css, screens/hero.png …   every project file at its relative path (binary files included)
  frame.png                                 one PNG of the design as OpenDesign renders it, when it can
  design.json                               the manifest
```

`design.json`:

```json
{
  "generated": "Generated by the opendesign extension from OpenDesign — do not edit; pull again instead.",
  "project": { "id": "…", "name": "Landing", "designSystemId": null },
  "source": "http://127.0.0.1:7456",
  "fetchedAt": "2026-10-31T18:00:00.000Z",
  "entry": "index.html",
  "frame": "frame.png",
  "files": [{ "path": "index.html", "mime": "text/html", "size": 1234, "sha256": "…" }],
  "skipped": [
    { "path": "../escape.txt", "reason": "the name does not stay inside the design folder" }
  ]
}
```

The folder is named from the project's own name (`slugOf` in `bundle.ts`). A second project with the same slug gets the
first eight characters of its id appended instead of overwriting the first one's snapshot. A file whose name would leave
the folder is never written — the manifest lists it under `skipped`, as are files over 8 MiB, past 400 files, or past
40 MiB in total. A file that disappears in OpenDesign is deleted from the folder on the next pull.

## Settings and the secret

Both settings are read from the project's `.ultimate/settings.json`, through `host.projectSettings()`:

```json
{ "opendesign.url": "http://127.0.0.1:7456", "opendesign.designsDir": "designs" }
```

- `opendesign.url` — the daemon. The default is OpenDesign's own `DEFAULT_DAEMON_URL`
  (`apps/daemon/src/daemon-url.ts`); `od` also honours `OD_DAEMON_URL`.
- `opendesign.designsDir` — where snapshots go, relative to the project root.

`OPEN_DESIGN_API_TOKEN` is a **secret** (`~/.ultimate/secrets.json`, added in ⌘K → Secrets), read server-side only and
never put in a result, the manifest, a tool output or a log line. It is only needed when the daemon does not trust this
machine: the daemon skips its token check for loopback peers (`apps/daemon/src/server.ts`), so a local app needs none;
Docker or a reverse proxy does. When it is required and missing or wrong, the message names the secret and where to add
it. From OpenDesign's settings the token is `OD_API_TOKEN`; basic auth uses the fixed username `open-design`
(`API_TOKEN_BASIC_USERNAME`, `apps/daemon/src/api-token-auth.ts`).

## The routes this relies on

Read from OpenDesign's source on 2026-10-31 (`git clone --depth 1 https://github.com/nexu-io/open-design`); check them
again if a newer OpenDesign answers oddly — a renamed route fails loudly, naming the path.

| route                                 | used for                                  | where it comes from                                                                                   |
| ------------------------------------- | ----------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `GET /api/active`                     | what the user has open                    | `apps/daemon/src/routes/active-context.ts` (`getActiveRoute`; five-minute TTL from `constants.ts`)    |
| `GET /api/projects`                   | the project list                          | `apps/daemon/src/routes/project/index.ts` (`/api/projects`)                                           |
| `GET /api/projects/:id`               | the project row, its `metadata.entryFile` | same file (`/api/projects/:id`)                                                                       |
| `GET /api/projects/:id/files`         | the file inventory                        | same file (`/api/projects/:id/files`; ignored dirs in `projects.ts`)                                  |
| `GET /api/projects/:id/raw/<path>`    | each file's bytes                         | same file (`/api/projects/:id/raw/*`), as `get_artifact` pulls files (`fetchProjectFile` in `mcp.ts`) |
| `POST /api/projects/:id/export/image` | the frame PNG                             | `apps/daemon/src/import-export-routes.ts` (`handleScreenshotExport`)                                  |

The entry file is resolved the way OpenDesign's own `get_project` resolves it (`resolveProjectEntry` in
`apps/daemon/src/mcp.ts`): `metadata.entryFile`, else `index.html`, else the single `.html` at the project's root.

The frame needs OpenDesign's desktop runtime, which renders it with Chromium; a web-only OpenDesign answers `501` and the
pull goes on without a frame, saying so in `design.json` and in the answer.

## What is not verified here

OpenDesign is not installed on the machine this was written on, so every route above was verified against a stub daemon
(`test/opendesign-extension.test.ts`), not against the app. To check the real thing in two minutes:

1. Start OpenDesign, open a project, and note its daemon: the default is `http://127.0.0.1:7456` (`od mcp` prints it, or
   `echo $OD_DAEMON_URL`).
2. Open ⌘K → **Show designs from OpenDesign**. With the app running on the default port the panel lists the project you
   have open first; if it says it cannot reach OpenDesign, set `"opendesign.url"` in `.ultimate/settings.json` to the
   address it printed. If it says OpenDesign refused the request, add `OPEN_DESIGN_API_TOKEN` in ⌘K → Secrets.
3. Press **pull** on the row, and check `designs/<slug>/`: the files, `design.json`, and `frame.png` when the desktop
   app is running.
4. From a conversation: ask an agent to `design_pull` and it writes the same folder.
